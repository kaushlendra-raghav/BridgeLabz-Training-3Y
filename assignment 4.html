Question 4: Frameset Layout

Note: The frameset and frame elements are obsolete in HTML5. The following is the legacy-style example requested by the assignment. Save it as a separate file if your instructor needs to see the old frameset syntax.

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Frameset//EN"
  "https://www.w3.org/TR/html4/frameset.dtd">
<html>
<head>
    <title>Frameset Layout</title>
</head>
<frameset rows="25%,75%">
    <frame src="navigation.html" name="topFrame" title="Navigation">
    <frame src="welcome.html" name="bottomFrame" title="Welcome Message">
    <noframes>
        <body>Your browser does not support frames.</body>
    </noframes>
</frameset>
</html>

Contents for navigation.html:

<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Navigation</title></head>
<body>
    <a href="home.html" target="bottomFrame">Home</a>
    <a href="about.html" target="bottomFrame">About</a>
    <a href="contact.html" target="bottomFrame">Contact</a>
</body>
</html>

Contents for welcome.html:

<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Welcome</title></head>
<body><h1>Welcome to My Website</h1></body>
</html>

Question 13: Text in Three Languages

Question 17: Form and Result Pages Using an Iframe

Below is the form page loaded in an iframe. Submitting it targets the result page in the same iframe. For a real submission workflow, use separate files named form.html and result.html.

Contents of result.html:

<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Result</title></head>
<body><p>Form successfully submitted.</p></body>
</html>

In form.html, use <form action="result.html" target="resultFrame"> and place the form page in a parent document with an iframe named resultFrame.

Question 20: Important Head Elements

This page uses the following head elements. Comments explain the purpose of each tag.

<!DOCTYPE html>
<html lang="en">
<head>
    <!-- Sets the page title shown in the browser tab. -->
    <title>Important Head Elements</title>

    <!-- Declares the character encoding. -->
    <meta charset="UTF-8">

    <!-- Provides a short description of the page. -->
    <meta name="description" content="An example page demonstrating important HTML head elements.">

    <!-- Identifies the author of the page. -->
    <meta name="author" content="Your Name">

    <!-- Sets the base URL used by relative URLs on the page. -->
    <base href="https://example.com/">

    <!-- Links to a favicon or another external resource. -->
    <link rel="icon" href="favicon.ico" type="image/x-icon">

    <!-- The style element can contain CSS; left empty as requested. -->
    <style></style>

    <!-- The script element can contain JavaScript; left empty as requested. -->
    <script></script>
</head>
<body>
    <h1>Important Head Elements</h1>
    <p>This page demonstrates common HTML head tags.</p>
</body>
</html>
