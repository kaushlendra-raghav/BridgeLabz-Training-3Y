<header class="selectors-header"><h2>CSS Selector Practice</h2></header>

  <p>This paragraph is styled with an element selector.</p>
  <p class="highlight-paragraph">This paragraph uses a class selector.</p>
  <p id="special-paragraph">This paragraph uses an ID selector.</p>
  <p><a href="https://example.com">This HTTPS link uses an attribute selector.</a></p>
  <section class="selector-parent">
    <p>Direct child paragraph (child combinator).</p>
    <div><p>Nested paragraph (descendant combinator).</p></div>
    <p class="adjacent-target">Adjacent sibling target.</p>
    <p>General sibling target.</p>
  </section>
  <ul><li>First list item</li><li>Second list item</li><li>Third list item</li></ul>

<footer class="selectors-footer">© 2026 Selector Practice</footer>

CSS Code

/* Element selector: styles all paragraphs in the main section */
.selectors-main p { line-height:1.6; margin:10px 0; }
/* Class selector: applies to elements with class="highlight-paragraph" */
.highlight-paragraph { padding:10px; background:#fff0c2; }
/* ID selector: targets one unique element */
#special-paragraph { color:#9b2226; font-weight:bold; }
/* Attribute selector: selects links whose href begins with https */
.selectors-main a[href^="https"] { color:#087443; }
/* Child combinator (>): only direct child paragraphs */
.selector-parent > p { border-left:3px solid #2475a8; padding-left:8px; }
/* Descendant combinator: all paragraphs inside selector-parent */
.selector-parent p { background:#f1f6fb; }
/* Adjacent sibling combinator (+): immediately following sibling */
.adjacent-target + p { color:#b42318; }
/* General sibling combinator (~): all later paragraph siblings */
.adjacent-target ~ p { text-decoration:underline; }
.selectors-header,.selectors-footer { padding:14px; text-align:center; background:#17324d; color:white; }
.selectors-header h2 { margin:0; }
.selectors-main { padding:18px; }

Q8. Box-Sizing Comparison Page

Default: content-box

Same declared width and padding

With content-box, padding and border are added outside the declared width, so the total rendered width is larger.

border-box

Same declared width and padding

With border-box, the declared width includes the content, padding, and border, so the total width stays at the set value.
