Q4. Responsive Typography

Typography That Adapts

Responsive typography uses flexible font sizes to keep text readable on mobile phones, tablets, and desktop screens. The clamp() function sets a minimum, preferred, and maximum size.

HTML Code

<section class="responsive-type">
  <h1>Typography That Adapts</h1>
  <p>Responsive typography uses flexible font sizes to keep text readable on mobile phones, tablets, and desktop screens. The clamp() function sets a minimum, preferred, and maximum size.</p>
</section>

CSS Code

/* clamp(minimum, preferred, maximum) scales typography with viewport width */
.responsive-type { padding:clamp(18px,5vw,56px); margin:0 auto; max-width:900px; text-align:center; }
.responsive-type h1 { font-size:clamp(1.5rem,4vw,3rem); line-height:1.15; margin:0 0 1rem; }
.responsive-type p { font-size:clamp(1rem,2vw,1.5rem); line-height:1.7; margin:0 auto; }
@media(max-width:700px) { .responsive-type { padding:18px; } .responsive-type p { line-height:1.8; } }

Q6. Responsive CSS Cheat Sheet

Filters

Apply visual effects to images.

filter: grayscale(100%);

Media Queries

Apply styles at chosen screen widths.

@media (max-width: 700px) { ... }

Responsive Design

Make content adapt to different devices.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Typography

Scale font sizes fluidly.

font-size: clamp(1rem, 2vw, 1.5rem);

Q9. Responsive Design Principles Summary

Fluid Layouts

Use relative units and flexible columns so content adjusts to available space.

width: 100%; max-width: 1100px;

Flexible Media

Prevent images from overflowing their containers.

img { max-width: 100%; height: auto; }

Breakpoints

Change layout when the viewport reaches a chosen width.

@media (max-width: 600px) { ... }
